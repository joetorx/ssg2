# ssg2

This repository contains a simple website builder. Useful for a personal website and/or blog.

## Requirements

Python 3.14+

## Usage

### Bootstrap the site

```
make init
```

### Build and preview the site

```
make serve
```

After this, the website build will be in the public folder.

### Make a post

```
make post
```

This is to initialize the metadata and a accurate timestamp.
